토큰 수는 추정값입니다

각 회사의 정확한 토큰 계산기는 프로그램 설치가 필요해 이 페이지에 넣을 수 없습니다. 대신 실제 토크나이저(OpenAI o200k_base, Google gemini-1.5-flash)를 내려받아 한국 제조업 실무 문장으로 측정한 뒤, 그 결과에 맞춘 추정식을 넣었습니다.

  • 피팅에 쓰지 않은 업무 문장 185개로 따로 검증했습니다.
  • 총액은 정확합니다. 여러 문장을 합산한 값은 실제와 OpenAI 계열 −1.7%, Google 계열 −0.2% 차이였습니다. 이 도구가 내놓는 월 비용은 이 수준으로 믿을 만합니다.
  • 문장 하나하나는 덜 정확합니다. 한 문장 기준 오차 중앙값 5%, 길이가 있는 업무 문장이면 평균 3~4%입니다.
  • 짧고 흔한 표현은 과다 계상됩니다. “확인했습니다. 감사합니다.” 같은 상투어는 AI가 통째로 외우고 있어 실제 토큰이 훨씬 적습니다(이 경우 실제 6개, 추정 9개). 추정식은 글자 종류만 보고 계산할 뿐 어떤 표현이 흔한지는 모르기 때문입니다.
⚠️ Claude는 한국어에 토큰을 훨씬 많이 씁니다 — 이 도구의 가장 중요한 발견입니다. 한글 한 글자가 GPT는 0.71토큰인데 Claude는 1.37토큰입니다. 약 1.9배입니다. 100만 토큰당 단가만 비교하면 Claude가 싸 보여도, 한국어 문서를 넣으면 토큰이 두 배 가까이 잡히므로 실제 청구액은 역전될 수 있습니다. 이 도구는 그 차이를 반영해 계산합니다.

측정 경로와 검증

  • GPT — tiktoken o200k_base를 직접 실행. 실제 GPT-5 API 응답과 대조해 모든 표본에서 정확히 +6 토큰 차이(대화 형식의 고정 오버헤드)만 났습니다. 즉 이 토크나이저가 GPT-5의 실제 토크나이저와 일치합니다.
  • Gemini — 실제 API 응답의 토큰 수를 읽어 측정. 2.5부터 3.6까지 Pro·Flash·Lite 전 모델이 같은 토크나이저를 씁니다(대조 확인).
  • Claude — count_tokens API 실호출. 아래 참조.

Claude는 어떻게 측정했나

Anthropic은 토크나이저를 공개하지 않아 내려받아 돌려볼 수 없습니다. 대신 Anthropic이 제공하는 count_tokens API를 실제로 호출했습니다. 이 API는 무료이고 (토큰 과금 없음) 해당 모델의 진짜 토크나이저 기준으로 세어 줍니다. 한국 제조업 실무 문장 107개를 모델별로 전부 보내 측정한 뒤 회귀로 계수를 맞췄고, 피팅에 쓰지 않은 문장으로 검증해 평균 오차 5%, 합산 −1.1%를 확인했습니다.

⚠️ 호출에는 Console API 키가 따로 필요합니다. Claude Code·Pro 구독 로그인으로는 안 됩니다 — 서버가 jwt auth is not yet supported on count_tokens로 거부합니다.

계산에 넣지 않은 것

  • 추론(thinking) 토큰 — 요즘 모델은 답하기 전에 속으로 생각하고, 그 분량도 출력 요금으로 청구됩니다. 실제 비용은 여기 표시된 값보다 높을 수 있습니다.
  • 캐시 할인 — 같은 내용을 반복해 보내면 입력 요금이 최대 90%까지 싸집니다. 반복 작업이라면 실제로는 더 쌉니다.
  • 대량 처리(Batch) 50% 할인 — 급하지 않은 작업을 모아 돌리면 절반 가격입니다.
  • 긴 문서 할증 — 입력이 아주 길어지면(OpenAI 27만 토큰, Gemini Pro 20만 토큰 초과) 단가가 올라갑니다.
