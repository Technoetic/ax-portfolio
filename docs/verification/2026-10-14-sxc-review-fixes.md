## 변경

1. **정직성 표기를 HTML 캡션으로 옮겼습니다.** 도식 안의 '가상 BOM 데모 · report 기대 출력'과 'PASS 범위' 각주는 표시 크기에서 읽히지 않았습니다. 캡션을 다음 문장으로 바꿨습니다. "가상 BOM 데모를 설명하는 그림과 애니메이션입니다. 실제 실행 기록이 아니며, 검증의 실제 범위와 결과는 릴리스 근거에서 확인합니다." 플러그인 README의 정적 도식 캡션과 GIF 캡션을 합친 문장입니다.
2. **본문을 형제 장(3·4장)과 같은 문형으로 바꿨습니다.** 본문은 "직접 설계한 Claude Code와 Codex를 지원하는 교차 검증 플러그인입니다"로 시작합니다. 본문에서는 두 뜻으로 섞이던 '계층'을 쓰지 않습니다. 대체 텍스트의 '계층 폐포'는 도식 라벨을 그대로 옮긴 것입니다. README 부제를 줄인 질문 "같은 질문에, 같은 답을 내는가?"를 큰 숫자 자리에 두고, 버전 칩을 그 옆에 붙였습니다.
3. **3행과 안내문을 정리했습니다.**
   - '결과 확인'은 V4(변이 검사)를 두 번 세지 않도록 "V1–V5 교차 검사(V4 변이 검사 포함) · SHACL↔SQL 위반 대조 · 리포트"로 바꿨습니다.
   - '추론과 지표'에서 기준 SQL을 빼서 "HermiT · Cube Core"만 남겼습니다. 기준 SQL은 본문에서 '따로 작성한 기준 SQL'로 설명합니다.
   - 안내문은 README의 데이터 범위 한정을 살려 "PASS는 해당 데이터에서 수행한 검사가 불일치를 찾지 못했다는 뜻입니다"로 시작합니다. 건너뛴 검사는 통과로 치지 않고, 검증하지 못한 범위(`not_proven`)를 함께 보여 준다는 점도 풀어 썼습니다.
4. **행동 유도를 형제 장 양식으로 바꿨습니다.**
   - 주소가 보이는 단일 'GitHub에서 보기' 버튼으로 바꿨습니다. 접근 가능한 이름이 화면 문구로 시작합니다(WCAG 2.5.3).
   - '빠른 시작', '릴리스·검증 근거', '같은 기술을 도서관 예제로 배우는 튜토리얼'은 텍스트 링크로 둡니다. 세 링크 모두 새 탭 표시(↗)와 화면 낭독기용 '(새 탭)'을 붙였습니다.
   - 도서관 튜토리얼(`technoetic.github.io/library-ontology-tutorial/`)은 같은 기술 묶음(PostgreSQL·RDF/OWL·HermiT·SHACL·Cube Core)을 도서관 예제로 설명하는 공개 튜토리얼입니다. SQL·RDF 검증은 브라우저에서 실행하고, HermiT 단계는 실제 실험의 저장된 결과를 보여 주며, 서버 실습은 내려받아 진행합니다. 이번에 처음 링크했습니다.

7. **애니메이션의 진행 점을 다시 맞췄습니다.** 각 단계 정지 프레임(1,100 ms)에서 점이 이미 다음 탭 아래에 있었습니다. 그래서 반복 10,640 ms 중 7,680 ms 동안 점과 '0N / 07' 문구가 다른 단계를 가리켰습니다. 플러그인 저장소에서 생성기를 고쳐 다시 만든 GIF를 복사했습니다(SHA-256 `bc8ab37d…f2ff58`).
   - 정지 프레임 7개는 모두 현재 단계에 맞습니다.
   - 남은 1,440 ms는 '점에서 가장 가까운 탭'을 기준으로 잰 값입니다. 이동 구간 2,520 ms 중 점이 아직 이전 탭에 더 가까운 시간입니다. 이동이 시작되면 강조 탭과 문구가 먼저 새 단계로 바뀌고, 점이 이전 탭에서 따라옵니다.

같은 장의 접근성·배치 보정:

- 애니메이션 토글은 이름('7단계 동작 애니메이션')을 고정했습니다. 상태는 `aria-pressed`와 아이콘(▶/❚❚)으로 나타냅니다.
  - 눌린 상태는 hover와 구분되도록 진한 배경과 안쪽 테두리를 따로 줍니다.
  - ▶에는 텍스트 표시 선택자(U+FE0E)를 붙였습니다.
  - GIF 상태에서는 이미지 대체 텍스트를 애니메이션 설명으로 바꿉니다.
- 이미지 칸의 비율을 고정(`aspect-ratio: 1200/560`)했습니다. 토글할 때 캡션과 버튼이 움직이지 않습니다.

  - 3행·안내문·캡션에 `word-break: keep-all`을 적용해 모바일에서 단어가 음절 중간에서 끊기지 않게 했습니다.
  - 본문과 안내문에는 `text-wrap: pretty`를 적용했습니다.
  - '교차 검증 플러그인'과 'PostgreSQL 17'은 끊기지 않게 묶었습니다.
- 제목 상한은 42px로 정했습니다. 긴 이름(44px에서 444px 폭)의 시각 무게와 세로 여유를 고려했습니다. 이 크기면 1440 폭에서 배지가 형제 장처럼 제목 옆에 붙습니다. 1차 배치(제목 52px, 링크 2줄 등 여러 값이 함께 다름)에서는 장 높이가 969px로 화면 900px을 넘었습니다.
