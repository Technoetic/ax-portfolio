## 변경

1. **정직성 표기를 HTML 캡션으로 옮겼습니다.** 도식 안의 '가상 BOM 데모 · report 기대 출력'과 'PASS 범위' 각주는 표시 크기에서 읽히지 않았습니다. 캡션을 다음 문장으로 바꿨습니다. "가상 BOM 데모를 설명하는 그림과 애니메이션입니다. 실제 실행 기록이 아니며, 검증의 실제 범위와 결과는 릴리스 근거에서 확인합니다." 두 문장은 플러그인 README의 정적 도식 캡션과 GIF 캡션을 합친 것입니다.
2. **본문을 형제 장(3·4장)과 같은 문형으로 바꿨습니다.** "직접 설계한 Claude Code와 Codex를 지원하는 교차 검증 플러그인입니다"로 시작합니다. '계층'은 layer 한 뜻으로만 씁니다. README 부제를 줄인 질문 "같은 질문에, 같은 답을 내는가?"를 큰 숫자 자리에 두고, 버전 칩을 그 옆으로 옮겼습니다.
3. **3행과 안내문을 정리했습니다.**
   - '결과 확인'은 V4(변이 검사)를 두 번 세지 않도록 "V1–V5 교차 검사(V4 변이 검사 포함) · SHACL 위반 대조 · 리포트"로 바꿨습니다.
   - '추론과 지표'에서 기준 SQL을 빼서 "HermiT · Cube Core"만 남겼습니다. 기준 SQL은 본문에서 '따로 작성한 기준 SQL'로 설명합니다.
   - 안내문은 PASS의 뜻과 `not_proven`을 쉬운 말로 풀었습니다.
4. **행동 유도를 형제 장 양식으로 바꿨습니다.**
   - 주소가 보이는 단일 'GitHub에서 보기' 버튼으로 바꿨습니다. 접근 가능한 이름이 화면 문구로 시작합니다(WCAG 2.5.3).
   - '빠른 시작', '릴리스·검증 근거', '같은 기술을 도서관 예제로 배우는 튜토리얼'은 텍스트 링크로 둡니다. 세 링크 모두 새 탭 표시(↗)와 화면 낭독기용 '(새 탭)'을 붙였습니다.
   - 도서관 튜토리얼(`technoetic.github.io/library-ontology-tutorial/`)은 같은 기술 묶음(PostgreSQL·RDF/OWL·HermiT·SHACL·Cube Core)을 브라우저에서 실습하는 공개 페이지입니다. 이번에 처음 링크했습니다.
5. **검증 근거 한 줄을 추가했습니다.** "v0.1.1 릴리스 기준 태그 CI 8개 작업 통과(PostgreSQL 17·HermiT·Cube 통합 포함)." 근거는 릴리스 본문의 "all eight jobs passed, including PostgreSQL 17 / HermiT / Cube integration"입니다.
6. **9장 '이력 요약'의 프로젝트 목록을 갱신했습니다.** 숫자 카드는 '3 Claude Code · Codex 플러그인'인데 목록에는 하네스 14만 있었습니다. 에이전틱 볼트와 semantic-crosscheck를 추가했습니다.
7. **애니메이션의 진행 점을 다시 맞췄습니다.** 각 단계 정지 프레임(1,100 ms)에서 점이 이미 다음 탭 아래에 있어, 반복 10,640 ms 중 7,680 ms 동안 점과 '0N / 07' 문구가 다른 단계를 가리켰습니다. 플러그인 저장소에서 생성기를 고쳐 다시 만든 GIF를 복사했습니다(SHA-256 `bc8ab37d…f2ff58`). 정지 프레임 7개는 모두 현재 단계에 맞고, 남은 불일치 1,440 ms는 점이 이동하는 구간입니다.

같은 장의 접근성·배치 보정:

- 애니메이션 토글은 이름('7단계 동작 애니메이션')을 고정하고 `aria-pressed`와 아이콘(▶/❚❚)으로 상태를 나타냅니다. GIF 상태에서는 이미지 대체 텍스트를 애니메이션 설명으로 바꿉니다.
- 이미지 칸의 비율을 고정(`aspect-ratio: 1200/560`)해 토글할 때 캡션과 버튼이 움직이지 않습니다.
- 정적 도식의 대체 텍스트를 도식의 실제 라벨에 맞췄습니다. HermiT를 생성 모델처럼 적었던 표현을 고쳤고 가상 데모 표기를 넣었습니다.
- 3행·안내문·캡션에 `word-break: keep-all`을 적용해 모바일에서 단어가 음절 중간에서 끊기지 않게 했습니다. 본문에는 `text-wrap: pretty`를 적용했습니다.
- 제목은 44px 상한을 유지했습니다. 52px로 키우면 1440×900에서 장 높이가 화면을 넘어 링크 줄이 하단 바에 가렸습니다(측정 969px > 900px).
