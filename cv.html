Claude Code · Codex 지원v0.30.0 · MIT

설정 하나에서 PostgreSQL·온톨로지·시맨틱 레이어 모델을 만들고, 같은 질문에 같은 답을 내는지 서로의 결과와 따로 작성한 기준 SQL로 대조하는 교차 검증 플러그인입니다.
